## [v1.0.0](https://github.com/hamforge/boost-github-workflow/compare/v0.1.0...v1.0.0) - 2026-08-03

### Initial release

The first stable release of **hamforge/boost-github-workflow**.

This package provides hamforge's opinionated GitHub workflow for Laravel Boost.

#### Included Skills

- `$github-workflow`
- `$github-capture-idea`
- `$github-create-issue`
- `$github-plan-roadmap`
- `$github-next-issue`
- `$github-investigate-issue`
- `$github-implement-issue`
- `$github-release-review`

#### Highlights

- Opinionated GitHub workflow for AI-assisted Laravel development
- GitHub CLI (`gh`) as the standard GitHub interface
- Portable Boost skills using `SKILL.md`
- Codex metadata through `agents/openai.yaml`
- Structural package tests protecting the distributed skill contract

Thanks to everyone who helped shape the workflow.
